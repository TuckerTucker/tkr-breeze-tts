# Decisions (ADR log)

The one Decision log (ADR-023): dated, immutable records of why the system is the way it is.

- **Authoring bar:** context, decision, consequences; alternatives for significant choices.
- **Written by:** `governance.adr_create` / `governance.adr_supersede` (3-digit numbering,
  supersession by read-time overlay — never edit a committed ADR).
- **Retention:** exempt — append-only history; immutability is the point, not a leak.
