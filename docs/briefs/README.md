# Intents (briefs)

Descriptions of what is TO BE: design briefs, proposals, target-state sketches.

- **Authoring bar:** dated, with the plan entity it feeds (`_tkr_kit/` id). An Intent whose
  subject has shipped is converted to a Model or retired — never left describing a built thing.
- **Written by:** human; the plan itself (`planning.*`) is the structured Intent tier.
- **Retention:** bounded — convert-or-retire on ship is the lifecycle.
