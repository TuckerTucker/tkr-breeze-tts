# Assertions (published claims)

What we have told the outside world: README claims, API guarantees, compatibility statements.

- **Authoring bar:** each assertion names its `reach:` (public/partner/internal) and, where
  descriptive, an executable `verify:` — published examples rot on API change.
- **Written by:** human; [`REGISTER.md`](REGISTER.md) indexes current assertions and their last
  verification.
- **Retention:** bounded — a register row per claim, replace-on-verify.
