# Promoted memory

Git-tracked disposition records promoted from machine-local findings in `.tkr-kit/work/findings/`.
Each YAML record carries its source identity, disposition, provenance, actor, and timestamp.

The current records are discarded findings with no retained body. They are kept only as an audit
trail that the source finding was reviewed; they do not describe current implementation behavior.
Architecture decisions, if adopted as formal records, belong in [`docs/adr/`](../../docs/adr/).
