# Historical design flows

The registered JSON flow in this directory is a dated input to the original mode-first wireframe
pass. It remains as design provenance, not as a description of the active navigation.

Current product flow starts in Voices or Speak, uses saved voices in Speak, and does not expose
Scripts unless its centralized product gate is enabled. See the
[current architecture model](../../docs/models/architecture.md) and
`ui/src/state/workspace.ts` for implementation truth.
