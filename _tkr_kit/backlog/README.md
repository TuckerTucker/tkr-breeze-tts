# Backlog

This directory is reserved for git-tracked work that follows a completed planning item: defects,
dependency changes, regressions, debt, and operational follow-ups. Construction history remains
in the product/capability/feature/slice/story hierarchy; follow-on work belongs here so completed
records do not have to be reopened.

No backlog items are currently committed. Add a documented schema before adding the first item;
the repository does not currently ship or claim a backlog CLI, service, or sustainment capability.
